# AI Video Analysis — Epistemic Archive

This repository contains a managed, evidence-first archive for reverse-engineering gaming-video humor, narration, editing, music, and audiovisual timing. Start with [`managed/README.md`](managed/README.md) for the collection structure and provenance rules.

**Status:** Initial archive from a ChatGPT discussion. Reference observations are not all independently verified. Original model responses, source transcripts, corrections and proposed architectures are stored separately so that hypotheses cannot masquerade as ground truth.

The repository is public; uploaded verbatim material is not anonymized or redacted as expressly requested by its submitter.
